# 数据库结构说明文档 (Content System)



**完整表清单 (共 14 张)：**

1. **技能大类表 (skill_categories)** -  题目技能维度(听说读写译)
2. **题型定义表 (exercise_types)** - 具体题目类型
3. **媒体资产表 (media_assets)** - 媒体表
4. **题目_媒体关联表 (exercise_media_assets)** - 记录题目和媒体之间的关系
5. **题目表 (exercises)** - 题目和词语关联
6. **阶段表 (phases)** - 课程体系顶层
7. **主题表 (topics)** - 阶段下的分类
8. **课程表 (lessons)** -主题下的分类
9. **课程_单词关联表 (lesson_words)** - 课程与词语关联
10. **单词表 (words)** - 
11. **卡片模板表 (card_templates)** 
12. **卡片资源表 (card_resources)** 

------

## 1. 技能大类表 (skill_categories)

系统的顶层分类法，用于定义“听、说、读、写、译”等核心能力维度。这是生成用户能力图谱（Radar Chart）的基础。

| **字段名**    | **类型**    | **说明** | **科学性/逻辑备注**                                          |
| ------------- | ----------- | -------- | ------------------------------------------------------------ |
| id            | UUID        | 主键     |                                                              |
| name          | VARCHAR(50) | 唯一标识 | 设有唯一约束（如 `listening`, `speaking`），用于代码逻辑判断。 |
| description   | TEXT        | 描述     |                                                              |
| display_order | INT4        | 排序     | 设有唯一约束，确保在 UI 上展示顺序固定。                     |

------

## 2. 题型定义表 (exercise_types)

定义具体的交互形式（如“听音选图”、“朗读句子”）。

| **字段名**        | **类型**     | **说明** | **科学性/逻辑备注**                                          |
| ----------------- | ------------ | -------- | ------------------------------------------------------------ |
| id                | UUID         | 主键     |                                                              |
| skill_category_id | UUID         | **外键** | 关联 `skill_categories`。这建立了从“具体题目”到“宏观技能”的映射路径。 |
| name              | VARCHAR(255) | 组件标识 | 唯一键。前端根据此字段决定渲染哪个 Vue/React 组件。          |
| display_name      | VARCHAR(255) | 展示名称 |                                                              |
| description       | TEXT         | 描述     |                                                              |
| display_order     | INT4         | 排序     | 组内唯一。                                                   |

------

## 3. 媒体资产表 (media_assets)

**单一事实来源 (SSOT)** 的媒体库。所有音频、视频、图片仅在此处存储一份元数据，防止系统内出现重复文件。

| **字段名**  | **类型**     | **说明** | **科学性/逻辑备注**                                          |
| ----------- | ------------ | -------- | ------------------------------------------------------------ |
| id          | UUID         | 主键     |                                                              |
| file_url    | TEXT         | 文件地址 | 设有**唯一约束**。从物理层面防止同一个 OSS/S3 文件被重复录入。 |
| file_type   | VARCHAR(50)  | 大类     | 如 `audio`, `video`, `image`。                               |
| mime_type   | VARCHAR(100) | MIME类型 | 如 `audio/mp3`，用于前端播放器兼容性判断。                   |
| description | TEXT         | 备注     |                                                              |
| created_at  | TIMESTAMPTZ  | 创建时间 |                                                              |

------

## 4. 题目_媒体关联表 (exercise_media_assets)

多对多关联表。实现了一个媒体文件被多个题目复用的能力（例如：一段听力材料对应 5 道选择题）。

| **字段名**     | **类型**     | **说明** | **科学性/逻辑备注**                                          |
| -------------- | ------------ | -------- | ------------------------------------------------------------ |
| exercise_id    | UUID         | **外键** | 关联 `exercises`。                                           |
| media_asset_id | UUID         | **外键** | 关联 `media_assets`。                                        |
| usage_role     | VARCHAR(100) | 用途角色 | **关键逻辑**。定义该媒体是作为“题干音频”(prompt_audio)还是“解析视频”(explanation_video)。 |

------

## 5. 题目表 (exercises)

核心业务表。采用**组合模式 (Composite Pattern)** 设计，支持树状题目结构。

| **字段名**         | **类型** | **说明**       | **科学性/逻辑备注**                                          |
| ------------------ | -------- | -------------- | ------------------------------------------------------------ |
| id                 | UUID     | 主键           |                                                              |
| parent_exercise_id | UUID     | **自引用外键** | `NULL`表示父题，非`NULL`表示子题。支持无限层级嵌套（如：试卷->大题->小题）。 |
| exercise_type_id   | UUID     | **外键**       | 关联 `exercise_types`。                                      |
| word_id            | UUID     | **外键**       | (可选) 关联 `words`。用于“练词”类题目，建立题目与知识点的直接映射。 |
| prompt             | TEXT     | 题干           | 题目文本。                                                   |
| metadata           | JSONB    | 动态数据       | **NoSQL 特性**。存储选项数组、正确答案 key、填空占位符等非结构化数据。 |
| difficulty_level   | INT2     | 难度           | 默认 1。用于自适应学习算法。                                 |
| quality_status     | INT2     | 质检状态       | 0:待审, 1:合格, -1:驳回。                                    |

------

## 6. 阶段表 (phases)

课程体系的最顶层容器（Level）。

| **字段名**    | **类型**     | **说明** | **科学性/逻辑备注**          |
| ------------- | ------------ | -------- | ---------------------------- |
| id            | UUID         | 主键     |                              |
| name          | VARCHAR(255) | 阶段名   | 唯一约束。                   |
| display_order | INT4         | 排序     | 唯一约束，保证线性学习路径。 |

------

## 7. 主题表 (topics)

课程体系的第二层容器（Unit/Theme）。

| **字段名**  | **类型**     | **说明** | **科学性/逻辑备注**         |
| ----------- | ------------ | -------- | --------------------------- |
| id          | UUID         | 主键     |                             |
| phase_id    | UUID         | **外键** | 关联 `phases`。             |
| topic_name  | VARCHAR(255) | 主题名   |                             |
| topic_order | INT4         | 排序     | 在所属 Phase 内的相对顺序。 |

------

## 8. 课程表 (lessons)

具体的学习单元。

| **字段名**    | **类型**     | **说明** | **科学性/逻辑备注**  |
| ------------- | ------------ | -------- | -------------------- |
| id            | UUID         | 主键     |                      |
| topic_id      | UUID         | **外键** | 关联 `topics`。      |
| lesson_name   | VARCHAR(255) | 课程名   |                      |
| dialogue      | TEXT         | 课文内容 | 存储长文本对话脚本。 |
| display_order | INT4         | 排序     |                      |

------

## 9. 课程_单词关联表 (lesson_words)

连接“课程”与“知识点（单词）”的桥梁。

| **字段名**    | **类型** | **说明** | **科学性/逻辑备注**                                      |
| ------------- | -------- | -------- | -------------------------------------------------------- |
| lesson_id     | UUID     | **外键** | 关联 `lessons`。                                         |
| word_id       | UUID     | **外键** | 关联 `words`。                                           |
| display_order | INT4     | 学习顺序 | 决定用户在课程中先学哪个词，符合教学法（Pedagogy）设计。 |

------

## 10. 单词表 (words)

原子化的知识点库。

| **字段名**  | **类型**     | **说明**  | **科学性/逻辑备注**                                          |
| ----------- | ------------ | --------- | ------------------------------------------------------------ |
| id          | UUID         | 主键      |                                                              |
| characters  | VARCHAR(100) | 词汇/汉字 | 唯一约束。                                                   |
| pinyin      | VARCHAR(255) | 拼音      |                                                              |
| translation | TEXT         | 释义      |                                                              |
| hsk_level   | INT2         | HSK等级   | 标准化难度指标，支持跨课程检索（如“列出所有 HSK1 级单词”）。 |
| audio_url   | TEXT         | 发音音频  |                                                              |

------

## 11. 卡片模板表 (card_templates)

卡片外壳。

| **字段名**       | **类型**     | **说明** | **科学性/逻辑备注**                                          |
| ---------------- | ------------ | -------- | ------------------------------------------------------------ |
| card_template_id | UUID         | 主键     |                                                              |
| title            | VARCHAR(255) | 标题     |                                                              |
| card_type        | VARCHAR(50)  | 类型     | 如 `exercise`, `video`。决定前端卡片的 UI 骨架。             |
| card_subtype     | VARCHAR(50)  | 子类型   | 如 `exercise_listening`。用于更细粒度的推荐算法逻辑。        |
| author_id        | UUID         | **外键** | 关联 `people.users` (注：该表不在本 Schema 中)。             |
| author_name      | VARCHAR      | 作者名   | **数据冗余**。牺牲范式以换取 Feed 流高并发读取时的性能（减少 JOIN）。 |
| likes            | INT4         | 点赞数   |                                                              |
| is_active        | BOOL         | 状态     | 上下架控制。                                                 |

------

## 12. 卡片资源表 (card_resources)

卡片内容表。

| **字段名**    | **类型**    | **说明**   | **科学性/逻辑备注**                                          |
| ------------- | ----------- | ---------- | ------------------------------------------------------------ |
| id            | UUID        | 主键       |                                                              |
| card_id       | UUID        | **外键**   | 关联 `card_templates`。级联删除。                            |
| resource_id   | TEXT        | **逻辑ID** | **多态关联核心**。它存储的是目标资源的 ID（如 `exercises` 的 UUID），但没有物理外键约束。 |
| resource_type | VARCHAR(50) | 资源类型   | 指示 `resource_id` 属于哪张表。                              |
| display_order | INT4        | 排序       |                                                              |

------
