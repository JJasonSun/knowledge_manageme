# 数据库结构说明文档 (Scenario Learning System)

**模块概述**：本模块独立于主课程体系，专门用于存储和管理由 AI 动态生成的内容。它包含任务队列状态、非结构化的生成内容（文章/对话）以及与之关联的动态题库。

**表清单 (共 10 张)：**

1. **生成任务/主题表 (topics)** - 生成任务的入口与状态追踪
2. **生成课程表 (generated_lessons)** - AI 产出的核心教学内容
3. **对话内容表 (dialogues)** - 结构化的对话脚本
4. **词汇库表 (vocabulary)** - 单词库 比theme下的单词多
5. **课程词汇包表 (generated_vocab_packages)** - 课程词汇集合
6. **情境练习表 (sl_exercises)** - 动态生成的题目
7. **情境题型定义表 (sl_exercise_types)** - 题型元数据
8. **情境技能分类表 (sl_skill_categories)** - 技能维度
9. **情境媒体资产表 (sl_media_assets)** - 媒体资源库
10. **练习媒体关联表 (sl_exercise_media_assets)** - 

------

## 1. 生成任务/主题表 (topics)

这是 AI 生成流程的起点，同时充当了**异步任务状态表**。

| **字段名**      | **类型** | **说明**   | **科学性/逻辑备注**                                          |
| --------------- | -------- | ---------- | ------------------------------------------------------------ |
| topic_id        | INT4     | 主键       | 使用 **Sequence (自增序列)**，区别于主系统的 UUID。适合按时间线管理的生成记录。 |
| topic_name      | VARCHAR  | 主题名称   | 用户输入的 Prompt 关键词。                                   |
| input_hsk_level | INT4     | HSK等级    | 约束 AI 生成难度的核心参数。                                 |
| job_id          | VARCHAR  | 任务ID     | **关键字段**。用于关联后台异步任务队列（如 Celery/BullMQ），前端通过此 ID 轮询生成进度。 |
| stage2_input    | JSONB    | 二阶段输入 | 暗示生成过程是**分阶段流水线**（如：大纲 -> 内容）。此字段存储中间态数据。 |
| user_id         | UUID     | 外键       | 关联主用户表。                                               |

------

## 2. 生成课程表 (generated_lessons)

存储 AI 生成的具体课文内容。

| **字段名**    | **类型**  | **说明** | **科学性/逻辑备注**                                          |
| ------------- | --------- | -------- | ------------------------------------------------------------ |
| lesson_db_id  | INT4      | 主键     | 内部数据库 ID。                                              |
| topic_id      | INT4      | 外键     | 关联生成任务 (`topics`)。                                    |
| lesson_name   | VARCHAR   | 课程名   |                                                              |
| type          | VARCHAR   | 类型     | 枚举值：`passage` (文章) 或 `dialogue` (对话)。              |
| passage       | JSONB     | 文章内容 | 若类型为文章，段落结构直接存为 JSON，避免了复杂的“段落表”关联。 |
| lesson_id_str | VARCHAR   | 业务ID   | **混合索引策略**。支持非整数 ID 格式，可能用于向量数据库检索或前端路由。 |
| generated_at  | TIMESTAMP | 生成时间 |                                                              |

------

## 3. 对话内容表 (dialogues)

针对 `dialogue` 类型课程的专用存储表，结构化程度比文章更高。

| **字段名**   | **类型** | **说明** | **科学性/逻辑备注**                                          |
| ------------ | -------- | -------- | ------------------------------------------------------------ |
| dialogue_id  | INT4     | 主键     |                                                              |
| lesson_db_id | INT4     | 外键     | 关联 `generated_lessons`。级联删除。                         |
| roles        | JSONB    | 角色列表 | 存储对话角色定义（如 `{"A": "Teacher", "B": "Student"}`）。  |
| dialogues    | JSONB    | 对话脚本 | 存储变长的对话行（Lines），JSONB 极适合这种嵌套结构，便于前端直接渲染。 |

------

## 4. 词汇库表 (vocabulary)

AI 生成或提取的原子单词库。

| **字段名**     | **类型** | **说明** | **科学性/逻辑备注**                                          |
| -------------- | -------- | -------- | ------------------------------------------------------------ |
| vocab_uuid     | UUID     | 主键     | 使用 UUID，方便未来将这些词合并到主词库中，避免 ID 冲突。    |
| word           | VARCHAR  | 单词     |                                                              |
| hsk_level      | INT4     | 等级     |                                                              |
| **Constraint** | Unique   | 唯一约束 | `(word, hsk_level)` 联合唯一。允许同一个词在不同难度等级下有不同的元数据。 |

------

## 5. 课程词汇包表 (generated_vocab_packages)

连接“AI 生成课程”与“单词”的中间表，定义了“这节课学什么词”。

| **字段名**          | **类型** | **说明** | **科学性/逻辑备注** |
| ------------------- | -------- | -------- | ------------------- |
| vocab_package_db_id | INT4     | 主键     |                     |
| lesson_db_id        | INT4     | 外键     | 关联生成课程。      |
| vocab_uuid          | UUID     | 外键     | 关联单词库。        |

------

## 6. 情境练习表 (sl_exercises)

基于生成内容自动产出的题目。

| **字段名**          | **类型** | **说明**     | **科学性/逻辑备注**                                          |
| ------------------- | -------- | ------------ | ------------------------------------------------------------ |
| id                  | UUID     | 主键         |                                                              |
| source_lesson_db_id | INT4     | **溯源外键** | **关键设计**。记录这道题是基于哪篇生成的课文产生的。若课文重生成，相关题目可级联清理。 |
| vocab_package_db_id | INT4     | 上下文外键   | 关联具体的词汇包记录。表明这道题考察该课程中的哪个具体单词。 |
| parent_exercise_id  | UUID     | 自引用       | 支持复合题型（大题套小题）。                                 |
| exercise_type_id    | UUID     | 外键         | 关联题型定义。                                               |
| metadata            | JSONB    | 题目数据     | 存储 AI 生成的选项、干扰项、解析等非结构化数据。             |
| difficulty_level    | INT2     | 难度         |                                                              |

------

## 7. 情境题型定义表 (sl_exercise_types)

定义 AI 生成题目的交互形式。

| **字段名**        | **类型** | **说明** | **科学性/逻辑备注**                            |
| ----------------- | -------- | -------- | ---------------------------------------------- |
| id                | UUID     | 主键     |                                                |
| name              | VARCHAR  | 唯一标识 | 前端组件渲染 Key（如 `ai_generated_choice`）。 |
| skill_category_id | UUID     | 外键     | 关联技能大类。                                 |
| display_order     | INT4     | 排序     |                                                |

------

## 8. 情境技能分类表 (sl_skill_categories)

定义 AI 练习覆盖的能力维度（听/说/读/写）。

| **字段名**  | **类型** | **说明** | **科学性/逻辑备注**         |
| ----------- | -------- | -------- | --------------------------- |
| id          | UUID     | 主键     |                             |
| name        | VARCHAR  | 名称     | 如 `listening`, `reading`。 |
| description | TEXT     | 描述     |                             |

------

## 9. 情境媒体资产表 (sl_media_assets)

AI 生成过程中的媒体文件（如 TTS 合成的音频、AI 生成的插图）。

| **字段名** | **类型** | **说明** | **科学性/逻辑备注**                  |
| ---------- | -------- | -------- | ------------------------------------ |
| id         | UUID     | 主键     |                                      |
| file_url   | TEXT     | URL      | 唯一约束。通常指向云存储（OSS/S3）。 |
| file_type  | VARCHAR  | 类型     | Audio/Image。                        |
| mime_type  | VARCHAR  | MIME     |                                      |

------

## 10. 练习媒体关联表 (sl_exercise_media_assets)

将生成的媒体资源挂载到题目上。

| **字段名**     | **类型** | **说明** | **科学性/逻辑备注**             |
| -------------- | -------- | -------- | ------------------------------- |
| exercise_id    | UUID     | 外键     |                                 |
| media_asset_id | UUID     | 外键     |                                 |
| usage_role     | VARCHAR  | 用途     | 如 `prompt_audio`（题干朗读）。 |
